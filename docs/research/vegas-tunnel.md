# Vegas 隧道战法

来源：用户提供的短视频（3分48秒，竖屏）。音轨用 Cloudflare Workers AI `@cf/openai/whisper-large-v3-turbo`
转写，原始转写见文末。本文把口播内容整理成可实现的规则。

## 参数

三组 EMA，全部取自斐波那契/平方数序列：

| 组 | 周期 | 角色 |
|---|---|---|
| 过滤器 | `EMA12` | 判定突破真假 |
| 快隧道 | `EMA144`、`EMA169` | 定方向：价格在其上方才考虑做多 |
| 慢隧道 | `EMA576`、`EMA676` | 定持仓：决定继续持有还是全部离场 |

慢隧道 = 快隧道 × 4（144×4=576，169×4=676）。
注意这几个数同时也是平方数：144=12²，169=13²，576=24²，676=26²。

**隧道是「区间」不是「线」。** 144 与 169 之间围成的带状区域才是隧道。原话：

> 单根均线，主力一根插针就能扫掉你止损。隧道是区间，单根 K 线短暂刺破不算有效突破，
> 天然过滤大量骗线 —— 这就是它比普通均线好用百倍的关键。

任何把隧道实现成单根均线的写法都丢掉了这套战法的核心。

## 三条规则

### 规则一：隧道上方只做多，隧道下方只看不做
解决的问题：**逆势抄底**。
价格站上快隧道，才站在概率正确的一边。不预测市场，只跟随市场。

### 规则二：`EMA12` 同步站上隧道，才算真突破
解决的问题：**分不清真假突破**。
价格刺破隧道但 `EMA12` 仍在隧道下方 → 判为假突破，不进场。原话说这条能砍掉约八成亏损单。

### 规则三：慢隧道不走平、不拐头，持仓不动
解决的问题：**拿不住单子**。
`EMA576`/`EMA676` 持续向上倾斜 → 大趋势未结束，继续持有让利润奔跑。
一旦慢隧道掉头向下 → 全部离场，不犹豫。

## 进场时机

口播里给的是**回踩隧道进场**，而不是突破当下追高：

> 快隧道 144、169 和慢隧道形成金叉多头共振，大小周期同步向上，大趋势方向已经确立。
> 从那时候回踩隧道进场，拿着不动。

所以完整的多头条件是四个同时成立：
1. 慢隧道向上倾斜（趋势成立）
2. 快隧道位于慢隧道上方（多头共振）
3. 价格位于快隧道上方（规则一）
4. `EMA12` 位于快隧道上方（规则二）

进场触发点：价格回踩至快隧道附近而未跌破。

## 实现上的硬约束

**`EMA576` 需要足够长的历史才算得准。** EMA 平滑系数 α = 2/(N+1)，N=576 时 α ≈ 0.003466，
初始种子的残留权重为 (1-α)^k：

| 历史根数 k | 种子残留权重 |
|---|---|
| 640 | **10.8%** |
| 1000 | 3.1% |
| 1330 | **1.0%** |
| 2000 | 0.1% |

腾讯接口上限 640 根 → 种子误差 10.8%，**不可接受**。日线要算准 `EMA576` 至少需要 ~1330 根
（约 5.3 年）。这直接推导出：历史 K 线必须自行落库积累，不能每次现拉。

## 未验证的部分

- 口播称此法源自 1980 年代芝加哥交易员 Vegas 的交易手册，未核实。
- 「砍掉八成亏损单」「避开 90% 无效亏损」等数字是口播说法，**没有任何回测支撑**，
  实现时不要把这些数字写进 UI 或文档当作事实。
- 口播中的存储芯片板块案例是事后归因，不构成验证。

**这套战法在本项目中的定位是「第一个可实现的策略」，不是「已验证有效的策略」。**
是否有效需要项目自己做回测来回答。
